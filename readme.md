## English
### Changes
#### HardMode
- Damage multiplier ×4
- KR multiplier ×4
- Game FPS set to 90 (supports higher values)

#### Settings
- NoHit: 1HP
- InfHP: Infinite HP, with a colored InfHP mark at the bottom right
- NoHeal: You have no food to eat
- SaBiMode: Replace all SFX with "mew mew mew", background music switches to Underpants BadTom
- Custom music
- Custom SFX
- NoKR : No KR
- LOVE : SetLV
- Random Attack mode : Intro and Final won't
- Seed : every roll now comes off a seeded generator, so the same seed always plays out the same way. It restarts with each fight
- TAS : the fight only moves when you ask it to. `]` steps one frame, holding it runs at ten frames a second, and the music walks forward with it. Whatever else you are holding is what that frame sees, so `]` with right is one frame of right. Menus are left alone
- ADHD : the heart never stops - letting a key go keeps the speed, it bounces off the walls, steering on one axis drops whatever the other was doing, and a diagonal needs a key from each axis held together. The blue soul gets it left and right only
- FPS : Set FPS(Affects Damage and Player Speed)

#### Custom attacks
- Custom attack > Make attack: write an attack in the browser, with the command list, a checker and one click to load it into the game
- Drop any of sans' own attacks straight into the editor to start from it or stitch several together

#### Hotkeys
- `R` — Retry battle
- `ESC` — Return to main menu
- `]` — Skip current attack round

### 改版内容
#### 困难模式
- 伤害倍率 ×4
- KR 倍率 ×4
- 游戏帧率设置为90（支持更高帧率）

#### 设置选项
- NoHit :一碰就死
- InfHP : 无限血量，右下角有个彩色的InfHP标志
- NoHeal：关闭玩家回血功能
- SaBi Mode(傻逼模式)：全部音效替换为喵喵喵，背景音乐切换为 Underpants BadTom
- 自定义背景音乐
- 自定义音效
- NoKR : 当你漏掉了一只怪(没有KR了) 
- LOVE : 设置LOVE 
- Random Attack : 每次攻击随机，开头和结尾不变
- Seed(随机种子) : 随机数已改成伪随机，同一个种子每次跑出来完全一样，每场战斗开始时重置
- TAS : 战斗只在你要求时前进。按 `]` 走一帧，长按以每秒10帧运行，音乐也跟着一帧一帧走。步进时按住的其他键就是那一帧的输入，所以 `]` 和 → 一起按就等于按了一帧 →。菜单不受影响
- ADHD(多动症模式) : 心一直动，松开方向键不清速度，碰墙反弹，按一个轴的方向键会清掉另一个轴的速度，只有同时按住两个轴的键才走斜边。同时按左右/上下会随机选一个方向。蓝魂只有左右
- FPS : 改FPS,这会影响Boss伤害，玩家移速等

#### 自定义攻击
- Custom attack > Make attack：直接在网页里写攻击，带指令列表、语法检查，一键加载进游戏
- 可以直接把原版的攻击加进编辑器，拿来改或者拼在一起

#### 快捷键
- `R` — 重新开始战斗
- `ESC` — 返回主菜单
- `]` — 跳过当前攻击回合
